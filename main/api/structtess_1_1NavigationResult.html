Detailed Description

Owned route or shared guidance, retaining its complete immutable input lease.

Exact freshness requires the same snapshot, conservatively including changes outside selected edges. A historic result remains readable after replacement but is not permission to execute it. Route steps retain each domain crossing. Guidance follows earlier settled states, including on zero-cost plateaus.
