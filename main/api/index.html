tess API reference

This reference documents the supported C++ API generated from the installed headers. Use the version-relative navigation above to return to the authored documentation, its learning paths, or the reference map.

tess is pre-1.0; see the stability policy.

Core worlds

  • tess::Shape fixes the world, chunk, and lattice dimensions at compile time.
  • tess::FieldSchema declares the typed fields in each chunk page.
  • tess::World combines shape, schema, and dense or sparse residency.

Pathfinding

  • tess::PathRequest carries one start and goal.
  • tess::PathScratch owns reusable A* work storage.
  • tess::DistanceFieldProduct retains a dense multi-goal distance product for reuse.

Simulation

  • tess::OperationBatch collects declared world edits for validation and execution.
  • tess::Schedule runs deterministic phase-ordered tasks.
  • tess::DeltaFrame publishes versioned changes to a consumer-owned presentation layer.

Diagnostics

  • tess::diagnostics::DiagnosticsSnapshot captures path, queued-phase, timing, trace, and allocation state.
  • tess::diagnostics::FlowAccounting accounts lifecycle admission, retention, and terminal outcomes.

Optional integrations

  • tess::EnttTilePositionAdapter and tess::FlecsTilePositionAdapter bind external entity storage without transferring ownership.
  • tess::gpu::WebGpuBackend implements the optional GPU transport boundary; pathfinding remains on the CPU.
